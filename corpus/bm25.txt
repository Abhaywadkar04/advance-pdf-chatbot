BM25 (Best Matching 25) is a lexical ranking function used in information retrieval to score how relevant a document or text chunk is to a search query. It is a bag-of-words retrieval function that ranks documents based on the query terms appearing in each document, regardless of their proximity within the document.

BM25 scores a document using three main signals:
1. Term Frequency (TF) — how many times a query term appears in the document. BM25 uses a saturating function so that the tenth occurrence of a word adds much less score than the second occurrence.
2. Inverse Document Frequency (IDF) — rare terms across the corpus contribute more to the score than common terms, since rare terms are more informative.
3. Document Length Normalization — longer documents are penalized slightly so that they don't score higher purely because they contain more words. This is controlled by a parameter called b.

BM25 has two main tunable parameters:
- k1 controls how quickly term frequency saturates (typical values range from 1.2 to 2.0).
- b controls the strength of length normalization (typical value is 0.75).

To make lookups fast, BM25 implementations rely on an inverted index. An inverted index is a data structure that maps each unique term in the corpus to a list of the documents or chunks in which that term appears, along with term frequency counts. This allows the search engine to quickly find all chunks containing a query word without scanning every document.

BM25 is considered a strong baseline for keyword-based (lexical) search. It excels at exact-term matching, such as product codes, names, acronyms, or rare technical identifiers, but it does not understand semantic meaning — a query for "car" will not match a document that only contains the word "automobile" unless both words are literally present.
